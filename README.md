# Engineering Playground

A public repository dedicated to learning, experimentation, and continuous improvement in software development.

This repository contains small projects, coding exercises, prototypes, and programming challenges built to strengthen software engineering skills across multiple languages, frameworks, and technologies.

## Purpose
- Practice programming concepts
- Explore different technologies
- Improve problem-solving skills
- Experiment with software architectures
- Build small but meaningful projects

## Technologies
This repository may include projects built with:

- Kotlin / Android
- C#
- GO
- C
- Python
- PHP
- SQL
- Artificial Intelligence experiments
- APIs and backend concepts

## Structure
Projects are organized by language or technology to keep the repository clean and scalable.

```txt
engineering-playground/
├── kotlin/
├── csharp/
├── c/
├── python/
├── php/
└── experiments/
```
